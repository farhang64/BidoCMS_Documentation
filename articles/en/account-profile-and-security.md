# Update your profile and secure your account

Select the displayed account name in the sidebar to open **Profile**. All authenticated users can use Profile even when the **Users** administration menu is hidden from their role.

## Profile details


1. Open **Profile details**.
2. Edit the fields you want to update.
3. Select **Save profile** and look for **Profile saved.** The display name in the sidebar updates after a successful save.

| Field | Purpose |
| --- | --- |
| **First name**, **Middle name**, **Last name** | Personal name fields stored on your account. |
| **Display name** | Name shown in the sidebar. The sidebar falls back to first and last name if the display name is empty. |
| **Phone number** | Optional contact number on the account. |
| **X username** | Optional X profile username. Changing it updates your account details. |
| **Email** | Read-only from Profile. Ask a CMS administrator to change the email used for sign-in. |

## Change password


1. Open **Security → Change password**.
2. Enter your **Current password**, then your **New password** and **Repeat new password**.
3. Use at least eight characters with a letter and a number and keep the password within 72 UTF-8 bytes.
4. Select **Change password**. Sign in again after the panel redirects you to the login screen.

## Turn on two-step authentication

1. Open **Security → Two-step authentication**.
2. Enter your current password and select **Set up two-step authentication**.
3. Scan the QR code with your authenticator app.
4. Enter the six-digit **Verification code** and select **Verify and enable**.
5. Confirm the panel shows **Enabled**. At future sign-ins, enter the current code for this account when asked.

While the panel displays **Awaiting verification · not enabled yet**, the QR code has been created and enrollment is pending. If the setup expires, choose **Cancel setup**, start again, and scan the new code. Canceling before verification leaves the account's existing setting unchanged. Keep the QR and six-digit codes private.

## Turn off two-step authentication

Open **Security → Two-step authentication**, enter your current password, and select **Disable two-step authentication**. Verify that the status changes to **Not enabled**.

See also [Sign in and recover access](account-sign-in.md).
