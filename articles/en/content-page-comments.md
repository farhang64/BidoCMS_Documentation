# Page comments

Open **Pages**, select a page and language, then select **Comment** when it is available. This tab requests comments for that page language.

## Current release behavior

The Comment panel currently fails to render existing comment records correctly. It also has no working panel controls for approving, replying to, or deleting comments. An empty or broken tab cannot establish whether the public page has comments. Ask the site administrator which comment workflow the active theme supports.

If this tab is missing, check the account's **Pages → Comments** menu permission. The site's public comment workflow also depends on the theme.
