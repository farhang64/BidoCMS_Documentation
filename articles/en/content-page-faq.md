# Add and reorder page FAQs

Open **Pages**, select a page language, then choose **FAQ**. Questions and answers belong to the selected language. Display on the public page depends on its theme template.

## Add a question and answer

1. Select **Add Question**.
2. Enter the **Question** and **Answer** in the new row.
3. Select the row's **Save**.
4. Repeat for other entries. Open a collapsed row by selecting its question title.
5. Save any edits before leaving the tab or switching language.

An entry is complete when both fields contain nonblank text. The core automatically manages the `FAQPage` reference using complete entries in their saved order. The page schema preview shows the generated entry when applicable. When there are no complete entries, the automatic reference is removed. Check [Page Schema](content-page-schema.md) to understand whether the structured data appears.

## Reorder or remove questions

Drag the row's handle to the new position, or focus the handle and use the up and down arrow keys. The panel saves the new order and announces the result. If order saving fails or the list changed in another session, reopen it before sorting again.

To remove a question, use **Delete FAQ** on the row and confirm. Check the preview after editing and publish to update the live page.
