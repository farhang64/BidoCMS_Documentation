# Add supplies, tools, and steps to a page

Open **Pages**, select a page and language, then choose **How To**. This workspace records the supplies, tools, and steps for a procedure separately from the page's rich-text sections.

## Use the How To tab

| Button | Fields to complete |
| --- | --- |
| Add Supply | **supply value**, such as a material used up during the task. |
| Add Tool | **Tool value**, such as a reusable item used to carry it out. |
| Add Step | **title** for the action and **body** for its instructions. |

1. Select the appropriate add button.
2. Fill in the fields of the new row.
3. Select **Save** on that row.
4. Repeat as needed. Each supply, tool, or step is saved separately.
5. To remove an item, select its trash icon and confirm.

In a multilingual site, repeat the process for each public language that needs the instructions. Check that the theme template displays the fields on the public page. Use a preview before publishing.
