# Page text and rich-text editor

Open **Pages**, select a page and language, then open **Text**. The selected theme template defines the available sections. A layout might contain one `main` field, multiple named blocks, or no editable rich-text section.

## Open and save a text section


1. Find the section you want in **Text** and select **Edit text**.
2. Make changes in the rich-text editor. The editor can create an empty section when you first open it.
3. Use the toolbar's save icon or **Save & close** from the editor menu. Wait for the save confirmation.
4. Reopen the section to verify the stored content as needed, then preview the public page.

The editor has a separate close control. Use the save action to persist edits before switching tabs or closing. The template controls the number and names of text fields, supported formats, and image variants available to a section. Edit metadata such as **Title** and **H1** under [Main Content](content-page-main-content.md).

## Formatting, media, and links

The toolbar includes undo and redo, formatting, heading and block styles, alignment, indents, numbered and bulleted lists, colors, links, media, symbols, text direction, and HTML source. Selecting text can show shortcuts for bold, italic, link, headings, quote, lists, and AI writing when available.

Use **Insert/edit image** to select an image from the album. The section's template configuration determines which image sizes the picker can provide. Where available, use the selected link's **Add nofollow** action to set its `rel` value. Use the HTML/source action only when your task requires it, and preview formatting on the public page after changes.

## Text insights



| Section | What it shows |
| --- | --- |
| Document outline | Heading levels and heading text. Select a heading to navigate to it. |
| Search Console queries | Web search queries for the saved page URL when Search Console is connected and you have access. The editor uses up to the last 90 days and orders results by impressions. |
| Word & phrase frequency | Frequent single words and phrases. Phrase-length filters, hover highlights, and match navigation help review repeated text. Common words are excluded for the text language. |
| Document overview | Counts for words, unique words, characters, and headings. |
| AI writing assistant | AI writing controls for selected text or the current document, subject to provider configuration and access. |

Drag the separator to adjust the available width where the layout shows the insights panel beside the editor. With the separator focused, the arrow keys also resize it. Home and End set its smallest and largest available widths. Review AI suggestions and save the text after applying changes. If Search Console queries are unavailable, first save a valid page URL for the selected language and check the [page's Search Console connection and data](analytics-page-search-console.md).
