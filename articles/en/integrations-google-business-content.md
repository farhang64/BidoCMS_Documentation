# Reply to Google reviews and publish business updates

Use **Social → Google Business** and select the intended branch before working in **Reviews** or **Posts**. Google can require a verified profile and sufficient account permissions.

## Read reviews and respond


1. Open **Reviews** and find the review for this branch. Choose **Load more** to read further results as available.
2. Open the reply controls and write or edit the business response.
3. Choose **Publish reply** for a first reply or **Save reply** after editing one. It is attached to the original review on Google.
4. Use **Delete reply** only if you intend to remove that business response. Use the Google review management tools to report an issue with the review itself.

## Create a post or share a published page


1. Choose **Posts → Create post**.
2. Select **Post type** for a new post or a published-page share.
3. For a published-page share, use **Search published pages** and **Find pages**. Select the intended **Published page**, then check the suggested text, language and read-only link.
4. Review **Post text**. A new post can include **Link (optional for a new post)**. A publicly reachable picture from the site can be specified in **Public photo URL from this site (optional)**.
5. Review **Post language**, for example `en` or `fr-CA`, and the selected branch.
6. Choose **Publish on Google**, then **View posts** when available to check the provider result.

The provider can mark a post **Published**, **Processing** or **Rejected by Google**. Open a post to see available actions. **Edit text** changes the post summary where supported. **Delete post** removes the selected update from Google after confirmation.

If a CMS page is absent from the picker, confirm that the desired language version has a public published URL. Checking saved edits in Pages alone does not add a page to the published chooser.
