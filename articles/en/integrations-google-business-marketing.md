# Manage Google Business photos, action links and performance

Open a branch in **Social → Google Business**. **Photos**, **Bookings & links**, **Performance** and **Google tools** cover the branch's public media, actions and selected statistics.

## Photos

1. Open **Photos → Add a photo**.
2. Enter **Public image URL from this site** and choose a **Photo category**.
3. Choose **Add photo to Google**. Use a URL that the provider can fetch publicly.
4. Review the provider's returned media cards. Use **Delete media** and confirm if an existing item should be removed from Google.

## Bookings and action links


1. Open **Bookings & links**.
2. To create an action, use **Add an action link** and choose a supported **Link type**.
3. Enter the **Destination URL** and select **Preferred link** if this action should be marked preferred.
4. Choose **Save link**. Open an existing action for its update controls, or use **Delete link** to remove it.

Google's Place Actions capability controls availability. An action link connects visitors to a destination such as a booking URL and does not add a bookings calendar to the CMS.

## Performance and Google tools



**Performance** shows the last 30 days returned by Google for the selected branch. Read the displayed start and end dates and the total for each metric. Returned metrics can include impressions and user actions such as direction requests or bookings. Empty metrics can mean Google had no data to return for that branch and period. If the panel indicates that the Performance API is unavailable, ask the administrator to check the central Google integration.

Use **Google tools** to open **Google Business Profile Manager** or **Manage review reports**. Google's own workspace is the destination for product catalog, ads, account permissions and other management tools.
