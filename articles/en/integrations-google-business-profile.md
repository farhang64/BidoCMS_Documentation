# Edit Google Business profile, hours, attributes and services

Go to **Social → Google Business** and select the correct branch. The sections save changes to that Google location. Available fields depend on the location type and returned provider data.

## Profile


1. Open **Profile**.
2. Review **Business name**, **Website**, **Primary phone** and **Business description**.
3. When **Storefront address** is displayed, review street address, city, province or state, and postal code. The form shows the country separately.
4. In **Business categories**, choose a **Primary category**. To add an available category, enter a query under **Find a category**, select **Find categories**, pick an item in **Google categories** and use **Add selected category**. Remove additional categories with their named controls.
5. Where editable, use **Business status** to switch between open and temporarily closed.
6. Select **Save profile**. The panel sends changed fields. **No changes to save** indicates the displayed values match the loaded profile.

When Google provides the links, **Open business on Maps**, **Open review link** and **Copy review link** are available here.

## Hours


- Under **Weekly hours**, add or edit an opening period with **Open day**, **Close day**, **Opens (HH:MM)** and **Closes (HH:MM)**. Choose **Save weekly hours**.
- Under **Special and holiday hours**, choose **Add special date**, enter the date and optional end date, then set the opening and closing time or **Closed all day**. Choose **Save special hours**.
- Use **Remove** on a row before saving the updated hours if that period should be removed.

The weekly and special hours forms save independently. Review both when making a holiday change.

## Attributes and services


| Tab | Workflow |
| --- | --- |
| Attributes | Review the location's editable attributes. Change the desired values and choose **Save attributes**. Attributes come from the provider and can depend on categories and location. |
| Services | Review structured and custom services, edit available descriptions, and use **Add service** where categories permit it. For a custom service enter **Service name**, **Category** and **Description**. Remove rows as needed and choose **Save services**. |

If the provider refuses a change or a field is absent, check the selected branch and the permissions and categories on the Google profile. Reload the branch if someone else may have edited it since the form opened.
