# Manage Instagram comments and conversations

Use the selected account's **Posts**, **Reels** or **Inbox** section in **Social → Instagram**. Reading comments or conversations and performing actions can require different Meta capabilities.

## Review or moderate media comments

1. Open the account's media list and select a post or reel.
2. Open the available comments view and choose **Load more comments** where needed.
3. For a reply, find the intended comment, open **Reply**, write your response and choose **Send reply**.
4. Use the available hide, show or delete actions according to the comment and the account's moderation capability. Read the confirmation carefully before deleting.

## Read and reply from Inbox

1. Open **Inbox** and check the account identity.
2. Select the conversation. Use **Load more conversations** or **Load older messages** if the entry you need is outside the current results.
3. If the account can send messages and the provider permits a reply in the conversation, enter the reply and send it. Use the supported photo attachment action if the composer offers it.
4. Check the thread after sending. Use the view's refresh control if the provider response and displayed thread are temporarily out of sync.

If Inbox is absent, verify the CMS submenu grant and the account's messaging capability. If you can read a conversation but cannot send, check the conversation's current eligibility and the account's send permission. Follow the message shown for the active conversation.
