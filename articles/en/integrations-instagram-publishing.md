# Draft, publish and schedule Instagram posts

Open **Social → Instagram** and select the intended account. Under **Posts**, choose **Create post**. This action is available to users and accounts with publishing access.

## Prepare a publication

1. Select **Format**: Image, Carousel, Reel or Story. The available list depends on your CMS grants.
2. Add the **Caption**. The panel accepts up to 2,200 characters. For story text that should appear in the media itself, include it in the uploaded image or video.
3. Select files under **Upload media**, then **Upload selected files**. Choose them in the intended display order. Alternatively expand **Use a media URL from this website**, enter a same-site HTTPS **Media URL**, choose **Media type** and select **Add media URL**.
4. Review each uploaded item. Add **Alternative text** to eligible images, and remove or replace any expired upload.
5. If you want a draft, optionally enter **Draft name** and choose **Save draft**. Resume from **Saved drafts → Open draft**. Choose **New draft** to reset the composer.
6. Leave **Schedule** empty to select **Publish now**. To schedule, enter a future time in the browser time zone shown and select **Schedule publication**.
7. Check **Publication history** for the current state. Uploading assets and submitting them can precede the published result.

## Format checks and troubleshooting

| Format | Required media |
| --- | --- |
| Image | One image. |
| Carousel | At least two items and up to 20 from the composer. Media can contain images or videos. |
| Reel | One video. |
| Story | One compatible media item. |

The composer accepts JPEG, PNG, WebP, MP4 and QuickTime where the selected format and provider accept them. An expired temporary upload must be removed and uploaded again. The composer accepts a future date for scheduling. Published caption editing is unavailable in this composer, so verify the caption before submitting.

| Publication history action | When to use it |
| --- | --- |
| Cancel | Stop an eligible preparing, queued or scheduled item before publication begins. |
| Check publication | Ask for confirmation on a submitted item. Submission means Instagram received the request. |
| Record as published | For an uncertain result, first verify the post on Instagram and then enter its published media ID. |
| Confirm not published | For an uncertain result, first confirm on Instagram that no post was created. |
| Copy caption to new draft | Reuse the caption from a failed or cancelled entry. Upload the media for the new draft. |

A submitted or processing state can still be awaiting the provider. Check the existing history entry and the Instagram account before submitting a duplicate.
