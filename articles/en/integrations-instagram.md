# Connect Instagram and manage account sections

Open **Social → Instagram** to connect a supported account through Meta. Each connected account has its own media, inbox and settings. Select its account tab before working.

## Connect or renew an account

1. Choose **Connect Instagram** and complete the Meta authorization flow using the account you intend to manage.
2. If the browser blocks the authorization window, allow it for this site and start again. Wait for the completion message.
3. Choose the connected account. To manage more accounts, use **Add Instagram account**.
4. Open **Profile** and verify **Username**, **Connection** and **Access expires**. Use **Refresh account** to reread the current profile or **Reconnect Instagram** when authorization is needed again.
5. To change the label that appears in the CMS, edit **Account name in this panel** and choose **Save name**.
6. If an account should no longer be connected, select it and use **Disconnect**, then confirm the account name.

## Find media, stories and insights

| Section | What you can do |
| --- | --- |
| Posts | Browse accessible posts, open media details, review comments and start **Create post** when the account can publish. |
| Reels | Open published reels and available details for them. |
| Inbox | Read available conversations and reply with the account's messaging permissions. |
| Profile | Review the connection, CMS label and expiry. |
| Active stories | Open active stories from Profile when that permission is available. Roles without Profile access may see **Stories** as a separate tab if granted. |
| Account insights | Open insights from Profile when available, or use the **Insights** tab if your role exposes it directly. |

For account insights, select **Metric**, optionally set **From** and **To**, and choose **Load insights**. Available metrics in the form include Reach, Views, Profile views and Followers. Individual media can expose its own Insights action depending on provider capability. If the report is empty, check the metric, period and account access.

If connection setup is unavailable, the installation's Instagram integration may still require provisioning. If the account can publish but Posts does not show existing content, media reading requires its own provider access.
