# Connect an X account and manage posts or conversations

Open **Social → X (Twitter)** to work with the selected connected X identity. The panel offers Posts, Inbox and Profile when role and provider permissions allow.

## Connect or refresh an X account

1. Choose **Connect X** and complete the X sign-in and consent flow.
2. Check **Profile** for the connected name and current status. Use **Open on X** when offered to verify the remote profile.
3. To manage another identity, use **Add X account** and select its account tab after authorization.
4. Use **Refresh profile** to reread account data or **Reconnect X** if authorization expired. **Disconnect** removes the selected account's local connection.

## Publish and manage posts


1. Open **Posts** and select **Create post** if your account can publish.
2. Enter **Post text**, up to 280 characters in the composer. With the media permission, attach one JPEG, PNG or WebP image up to 5 MB. Links can be included in the text.
3. Verify the active account and select **Publish post**.
4. Use **Refresh posts**, then open the relevant post to see the provider URL and any available replies or management actions.

**Replies** are shown when the provider grants readable replies. Replying, moderating or deleting requires the corresponding capability and an eligible item. If the panel does not show an edit action, use the operations currently available for the post.

## Check the inbox


Open **Inbox**, select a conversation and use **Load older messages** to read previous messages. Use the inbox and thread refresh actions when needed. The reply field appears when both the account grant and conversation allow it. Choose **Send reply** to respond from the selected account.

If Posts or Inbox reports insufficient access, check the app permissions and reconnect with the appropriate scopes if they are available for this installation's X app. In some cases the provider's API cannot return an individual message or support a thread action. The panel displays the returned limitation.
