# Image album, uploads, and folders

Open **Images** to organize the reusable media album. Regular folders hold image files. Virtual tag folders show files associated with a tag.

## Open a folder and select images

- Click a thumbnail to select one image. Hold **Shift** while clicking to add images when the picker allows multiple selections.
- Double-click a folder to open it. The `..` folder returns to its parent.
- Select one image and choose **Details**, or double-click it, to open its detail tabs.
- When opening the album from a page or another picker, choose the permitted number of files and click **Select**. Save the originating page's field when required.

When available, the panel URL reflects the open folder, tag, image, and image detail tab. A saved panel link remains subject to the recipient's access.

## Import or organize files

1. Open a regular folder.
2. Select **Import** and choose one or more image files. The uploader accepts up to 5 MB per file.
3. Wait for the upload messages. A single successful upload can open its detail panel automatically.
4. Select **New Folder** to create a subfolder, if needed. The initial name is **new folder**.
5. Edit the label of a regular folder or image by selecting its displayed name when the inline name input is available.

The album also accepts an image dragged onto the gallery. Use **Import** for several files at once. An image's title can be initialized from its EXIF description or filename. Caption and alt text can come from EXIF values. Open **Detail** and review the imported metadata, especially for meaningful images.

## Delete an item or troubleshoot an import

Select the folder or images, choose **Delete**, and confirm the requested deletion. Deleting a regular folder also deletes its child folders and the images in it. The root folder cannot be deleted. Check where images are used in pages or as site branding before removing them.

If **Import** or **New Folder** reports a virtual directory restriction, navigate to a regular folder. For a failed file upload, check the file size and use a supported raster format such as JPEG, PNG, WebP, GIF, AVIF, or TIFF. The album accepts an image per upload request and can send multiple files from **Import**. If the gallery lists no matching items in a tag folder, check the image's tag assignment.
