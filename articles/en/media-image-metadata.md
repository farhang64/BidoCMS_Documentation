# Image alt text, titles, captions, and tags

Open **Images**, select an image, and choose **Details**. Use **Detail** for localized text and **Tags** for organizing the album.

## Edit the metadata of one language


1. Open the **Detail** tab.
2. Find the part of the form with the intended website language.
3. Enter **Alternative text**, **Title**, and **Caption** as needed.
4. Select the **Save** beside that language.
5. Repeat for the other configured languages.

**Alternative text** describes the meaningful content of the image. **Title** gives the image a label. **Caption** provides supporting context if the template shows it. Use the actual language of each form section. The theme determines which metadata it includes in the public page.

## Write descriptions with AI

1. Select **Write descriptions with AI**.
2. Choose a configured provider key and model.
3. Review the list of website languages and edit **Instructions** as needed. Use **Reset to standard prompt** to restore the default wording.
4. Enable **Include website context** to send the context from **Site → General → Website context for AI**, if configured.
5. Select **Generate and save for all languages**.
6. Review the saved fields in every language, then manually correct any wording as needed.

This action replaces alternative text, title, and caption across all configured website languages and saves the generated values automatically. If the action asks for setup, enable AI and a provider key first.

## Assign or remove an image tag


Open the **Tags** tab and choose **Add New Image Tag**. Select an **Image Tag** from the list and click **Save**. Use the row's delete action to remove the assignment. The tag itself can still be available for other images.

If **Tags** is absent, check your role and whether the site has any image tags. The shared list is managed in [Site → Image Tags](site-image-tags.md).
