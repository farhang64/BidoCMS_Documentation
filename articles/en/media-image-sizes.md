# Crop, scale, and rotate image variants

Open **Images**, select one image, choose **Details**, and then select a tab labeled with a size such as **1200×630**. The available dimensions come from the installation's image size configuration. A theme text field can limit the picker to only the variants it uses.

## Adjust the selected size

1. Open the required dimension tab and check the crop frame.
2. Drag the picture within the frame to position the subject.
3. Use **fix W** to fit the source width or **fix H** to fit its height.
4. Choose **Scale** or **Rotate** before adjusting. Depending on the device, use the wheel or the visible **−** and **+** controls.
5. Use the color picker to change the background visible behind the image.
6. Select **save image** and wait for upload confirmation. Repeat for other dimensions as needed.

The **reset** control reloads the original for the current editing session. Save after resetting if you want new output for this variant. Each saved result is a WebP variant for the selected dimensions. Open **Source** to view or edit the original through the AI workflow.

If a size tab is missing, check your **Images → Image sizes** permission, the size list configured for the installation, and restrictions from the originating text or page picker.
