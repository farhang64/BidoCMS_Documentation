# Browse and manage installation files

Open **Files** to work with accessible files in the installation storage. This workspace is for administrators. **Images** is the separate workspace for the site's managed media records and image metadata.

## Browse and select


- Use the folder breadcrumbs and **Up** to move around the allowed storage root. Select **Refresh** to reload the current folder.
- On desktop, double-click a folder or file to open it. On touch screens, tap the entry's name. With a keyboard, focus the name and activate it.
- Use the row checkboxes or the header checkbox to select items for toolbar actions. **Name**, **Size**, and **Modified** help identify the current copy.
- Supported images open a preview, and supported text files open an editor.

## Toolbar actions

| Action | How to use it |
| --- | --- |
| **New folder** | Open the parent folder, choose **New folder**, and enter the folder name. |
| **Upload** | Open the destination, select **Upload**, and choose one or more files. Check the refreshed list after the upload confirms. |
| **Download** | Select files and choose **Download**. For a directory, create a ZIP first and download the ZIP. |
| **Edit** | Select exactly one supported text file and choose **Edit**. Make the change and select **Save** or **Cancel**. |
| **Rename** | Select exactly one item, choose **Rename**, and enter its new name. |
| **Copy**, **Cut**, and **Paste** | Select the source items, choose **Copy** to duplicate or **Cut** to move, navigate to the target folder, and select **Paste**. |
| **Zip** | Select the files or folders, choose **Zip**, and enter an archive name. The archive is created in the current folder. |
| **Unzip** | Select one `.zip` file and choose **Unzip**. Extraction targets the current folder. Review the results in that folder. |
| **Delete** | Select the intended items, choose **Delete**, verify the number in the confirmation, and confirm removal. |

## If a file cannot be changed

The editor can read supported text files up to 1 MiB and accepts saves up to 2 MiB. For larger files or unsupported extensions, use your approved external workflow. Operations also enforce path, file, and archive checks. Protected data, security-sensitive paths, and invalid archives may be rejected. If a move or extraction fails, start by checking the destination, available space, and the error message. Avoid editing generated output when the long-term change belongs in the source page or theme, since publishing can replace generated output.

See also [Publish site changes](site-publishing.md) and [SSH access](operations-ssh-access.md).
