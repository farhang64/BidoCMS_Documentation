# Open the Notes workspace

**Notes** is a sidebar menu entry that opens an empty workspace in the current shared BidoCMS panel. It displays **There is nothing to display yet.** The current view provides no controls for creating, editing, saving, or sharing notes.

## Locate the menu

Open the sidebar or the mobile navigation drawer and select **Notes**. Ask your administrator to review the role grant if you expected to see the entry. Site-specific tools can have their own documentation and controls when supplied by the installation's theme or app.

See also [Find your way around the BidoCMS panel](start-panel-navigation.md).
