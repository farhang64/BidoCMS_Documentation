# Site image tag list

Open **Site → Image Tags** to maintain the list of tag names available in the image album. Tags can support categories such as `Team`, `Products`, and `Office`.

## Work in the panel

1. Open **Site → Image Tags**.
2. Edit **image tags list data**, keeping one name per line.
3. Select **Save** to update the list.
4. Open **Images**, select an image, and open **Details → Tags** to assign one of the listed tags.

The Site editor operates on the complete active list. Names omitted from the submitted list are deactivated. Adding the same name again reactivates the tag. Review the other names before saving a change. Assign tags to individual images in [Images](media-image-metadata.md). Tag folders in the album show images already associated with a tag and are separate from regular upload folders.
