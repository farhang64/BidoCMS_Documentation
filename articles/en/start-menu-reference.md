# BidoCMS panel menu reference

Find the help article for a sidebar menu or tab. The names below follow the English **Users → Roles** menu catalog. Visible workspaces depend on your role, installation version, and feature configuration.

The sidebar uses **Notification** to open the Notifications dashboard, and **Settings → Analytics** opens the Google Analytics connection. **AI & Agent** can contain the AI and Agents workspaces. The Social selector can show placeholders for unavailable providers. Check [Social workspace availability](integrations-social-overview.md) for current status.
