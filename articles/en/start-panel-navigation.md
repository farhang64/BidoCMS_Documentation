# Find your way around the BidoCMS panel

The BidoCMS panel is the administration workspace for one installation. Open the sign-in address supplied by your administrator. Each installation can have its own site domain and CMS address.

## Open a workspace



1. Sign in with your administrator-provided email. Complete a verification code or password-change prompt if the panel asks for one.
2. Choose a workspace in the sidebar. On a narrow screen, use the **Open navigation** button to open the menu drawer, choose a workspace, and return to the panel.
3. Open any tabs inside the workspace. A feature may show additional tabs after you select a page, image, role, or account.
4. Use the browser's Back and Forward buttons to move through the panel areas you visited. Some workspaces support a direct browser link to a selected item. Opening that link still requires permission to access the item and its workspace.

## Use the header


| Control | Purpose |
| --- | --- |
| **Open Website** | Opens the public website. Check the public page there after publishing. |
| **Publish All Pages** | Starts a site-wide publication for roles allowed to publish. Use it for changes intended to affect the whole site. |
| Contextual actions | The current workspace can add controls such as **Refresh notifications**, a page publication action, or a theme-related publication action. |
| **Help** | Opens the English documentation for BidoCMS in another browser tab. |

On mobile, the **Website and publishing actions** button opens a compact menu for site and publishing actions. The side menu and the header actions serve different purposes. The product name and version appear in the header. A site can also show its own name and image.

## Which menus you can see

The sidebar and workspace tabs are filtered using your role. For example, access to **Users → Roles** and **Users → Users** can differ. An administrator role is also required for several operational settings, even where their menu is visible to a delegated account. Access to a menu can also depend on whether a parent menu is included in the same role.

Select your display name in the sidebar to open **Profile**. Use **Log out** to end your browser session, especially on a shared device.

| If you are trying to… | Start here |
| --- | --- |
| Change public content or upload images | **Pages**, **Images**, or **Site**, depending on the change |
| Confirm a change is publicly visible | **Publish**, then **Open Website** |
| Find site health and recent activity | **Notification**, **Monitor**, or **Console** |
| Manage team access | **Users → Roles** or **Users → Users** |
| Change panel defaults or configure connections | **Settings** |
| Reuse website content in another CMS | **Export** |
| Handle products, orders, customer portals, or another site-specific workflow | Check the installed site's theme or app for its own documentation. The shared BidoCMS menu catalog does not define a universal commerce or customer-management workspace. |

If a colleague can see a control that is missing from your screen, tell your administrator the full menu and tab name, the action you were trying to take, and which installation you signed into. On a phone, first check the open navigation drawer and the tab strip.
